# WanderWise Travel Website

A responsive React + Vite frontend prototype for a travel discovery and booking website.

## Requirements
- Node.js 18 or newer
- VS Code (recommended)

## Run locally
1. Extract the ZIP folder.
2. Open the extracted `wanderwise` folder in VS Code.
3. Open Terminal > New Terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL Vite prints, usually `http://localhost:5173`.

## Production build
Run `npm run build`. Vite creates the production website in the `dist` folder.

## Included
- Responsive desktop/tablet/mobile layout
- Destination search and category/budget filters
- Wishlist toggle
- Package details modal
- Demo booking request form
- Newsletter email validation
- Mobile navigation
- Required footer credit: Project Developed By: Nidhi Yadav

## Important
This is a frontend demo. It does not process payments, create real reservations, authenticate accounts, or send newsletter emails. Booking and newsletter interactions are simulated in the browser. Destination images load from Unsplash and Google Fonts is used for typography, so internet access is needed for those assets.
